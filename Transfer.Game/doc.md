## Загрузка видео
Загрузка видео происходит с помощью ФФмпег, а именно программа получает на вход путь к видеофайлу. Путь можно получить двумя способами. Или вы открываете видео
с помощью программы или сами находите его в проводнике программы.
Далее с помощью того же ФФмпег видео разделятся на аудио, которое впоследствии отправляется сначала в временное хранилище компьютера, а затем в хранилище приложения. Я не нашел способа без разделения поместить аудио в Track, поэтому такие лабиринты. 
По сути сейчас я в двух словах объяснил работу всего приложения, поэтому вы можете не читать код.
## Аргументы к ФФмпег
Аргументы к ФФмпег собираются из класса FFmpegArgument. Там существует несколько аргументов, значение которых можно изменять, далее все это применяется в разных частях программы для разных ситуаций. Пока что поддержка лишь формата mp4, но я не думаю что это надолго, по крайней мере я постараюсь оптимизировать всю работу этой шняги с меньшим ухудшением качества. 
## Конфиг
Конфиг вы можете найти под названием app.ini, в нем хранятся как данные для работы с интерфейсом, так и данные для работы в ФФМпег, например Аудиокодек и битрейт можно изменить, аудикодеки не бесконечны
По дефолту стоит libmp3lame, который вы можете изменить. Битрейт аудио по дефолту 128, вы можете изменить его как в лучшую, так и худшую сторону, но это повлияет
на скорость работы. Вообще в конфиге лучше ничего не менять для наилучшей работы. Или менять в случае ошибок.
Так же вы можете изменить кодек видео. Поэтому вот список всех кодеков из enum

```csharp
public enum AudioCodecs
{
    libmp3lame,
    eac3,
    ac3,
    libfdk_aac,
    libvorbis,
    aac
}
public enum VideoCodecs
{
    libx264,
    libx265,
    libvpx,
    libtheora,
    png,
    mpegts
}
```
